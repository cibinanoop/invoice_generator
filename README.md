# Luxe Invoice Studio

A polished, client-side invoice generator designed for GitHub Pages.

## Features
- Luxury, professional invoice design
- Live preview
- Add/remove unlimited line items
- INR, USD, EUR and GBP
- Tax and discount calculation
- Custom accent color
- Local browser autosave
- Download invoice as PNG
- Download invoice as A4 PDF
- Responsive editor for smaller screens
- No backend required

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `app.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/root`.
6. Save and open the generated GitHub Pages URL.

All invoice data stays in the browser's local storage. No invoice data is sent to a server.

## Optional improvements
For a production SaaS version, add customer profiles, invoice history, logo upload, multiple templates, payment links, GST fields, recurring invoices, and cloud storage.
